With AI, the first 80% of a software product takes days. The last 20% — security, tenancy, reliability, the audit trail — still takes engineering. We do both halves, and we say which one you need.

### What we open-source

Production work leaves reusable parts, and we publish them instead of keeping them in a drawer. The public pieces come from our e-commerce work:

| | |
| --- | --- |
| [**uplab-vendure-plugins**](https://github.com/Uplab/uplab-vendure-plugins) | Plugins for the [Vendure](https://vendure.io) commerce framework — SMS, delivery, payments and fiscalization for the Ukrainian market. Published to npm under [`@uplab`](https://www.npmjs.com/org/uplab). |
| [**vendure**](https://github.com/Uplab/vendure) | Our working fork of Vendure core. Framework bugs we hit in production get [fixed upstream](https://github.com/vendurehq/vendure/pull/5006), not patched around. |
